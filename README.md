# Sky Sprint (Flappy Runner)

If you are looking at `index.html` in a **Diff/PR viewer**, the game will **not run there**.
A diff page only shows code changes; it does not execute HTML/JavaScript.

## Run the game locally

### Option 1: Open directly
1. Download/clone this repo.
2. Open `index.html` in a browser (Chrome/Edge/Firefox/Safari).

### Option 2: Serve locally (recommended)
From the project folder:

```bash
python -m http.server 8000
```

Then open:

- <http://localhost:8000>

## Controls
- **Space** or **Arrow Up**: flap
- **Click/Tap** canvas: flap
- **Start / Flap** button: flap/start
- **Restart** button: reset game
